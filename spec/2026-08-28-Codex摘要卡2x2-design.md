# Codex 摘要卡 2×2 修复

## 问题

Codex 新增 GPT reserve 额度后，摘要区从 2×2 扩展成 3×2；昨日 Token 又占据一个卡位，
导致摘要区信息过多，卡片底部与“近期任务”视觉粘连。

## 方案

- Codex 摘要固定两列两行。
- 只显示 Codex 5 小时剩余、Codex 7 天剩余、可用额度、重置/Tibo。
- GPT reserve 7 天额度不在摘要区展示。
- 昨日 Token 保留在数据源与近 7 天图表中，不再显示为摘要卡。
- 摘要区与“近期任务”之间增加 4pt 间距。
- Claude 页面保持现有布局，不受影响。

## 验证方式

1. 单元测试确认 GPT reserve 与昨日 Token 不进入 Codex 摘要。
2. 完整测试与 Release 构建通过。
3. 替换正式应用后检查真实界面为 2×2，且摘要与近期任务之间有清晰间距。
