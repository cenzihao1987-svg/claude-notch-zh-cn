# Claude 会员识别与单页布局

## 目标

- 只读 Claude Desktop 已缓存的官方组织资料，识别 `Pro` 与 `Max`，不新增网络请求。
- 明确识别为 Pro 时隐藏 Fable 与可用额度；Max 保留两项；无法识别时维持原展示，避免误伤 Max。
- Claude 不再展示任何费用数据；Claude 与 Codex 都把额度、近 7 天用量和近期活动合并为一页。
- Codex 与官方客户端保持一致，数字和圆环均展示剩余额度：100% 为绿色满环，余额下降时圆弧从顶部顺时针减少，剩余 34% 以下变黄、15% 以下变红。Claude 保持展示已用比例。
- 展开宽度增大，收起宽度与顶部 `+10px` 悬停热区保持不变。
- 展开态左右内容边距为 24px；顶部同时显示 Claude/Codex 图标并标明当前选中项。
- 展开与收起时，当前来源图标和右侧用量组件跟随宽度变化平滑位移，不跳位。
- 额度百分比提高一级字号，高用量红色在黑底上保持清晰警示。

## 数据边界

- 会员等级只读取 Claude Desktop Chromium Cache 中的组织资料响应。
- 只解析 `capabilities`：`claude_pro` → Pro，`claude_max*` → Max。
- 不记录缓存正文、组织 ID、账号信息；缓存缺失或格式变化时返回未知。

## 展示规则

- Pro：5 小时、7 天、近 7 天 Token、近期会话。
- Max：在 Pro 内容上增加 Fable 与可用额度。
- 未知：沿用原有 Fable/可用额度展示条件，保证现有能力不丢失。
- Claude 的今日、累计、图表和会话均不显示美元费用，仅显示 Token。
- Claude 与 Codex 都取消横向滑动和分页圆点。

## 验证方式

1. 用脱敏 JSON 单测验证 Pro、Max 和未知能力解析。
2. `swift build -c release` 编译通过，`git diff --check` 无格式错误。
3. 运行独立测试 App：Pro 页面无 Fable、可用额度及费用；Claude/Codex 的左右滑动和分页圆点消失；展开区域更宽；顶部图标与用量组件随展开/收起平滑位移；移出后正常收起。
