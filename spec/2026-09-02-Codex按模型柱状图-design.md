# Codex 按模型柱状图

## 目标

Codex 展开面板中的近 7 天柱状图使用官方“分析”数据，按模型显示每日套餐用量占比。

## 数据与安全

- 只读 `chatgpt.com` 官方用量路径，使用本机 Codex 已有登录文件。
- 访问令牌、账号 ID 和原始响应只存在内存，不写缓存、不进日志。
- 使用无 Cookie、无磁盘缓存的临时网络会话，拒绝跳转到非目标路径或域名。
- 成功结果缓存 60 秒；失败后 5 分钟再尝试。
- 官方模型数据不可用时回退到原账号 Token 柱状图，不展示推算或过期模型占比。

## 展示

- 每日柱子按模型堆叠，固定展示 0–100% 的套餐用量比例。
- Sol 为蓝色、Terra 为橙色、Luna 为绿色；最多单列三个模型，其余合并为“其他”。
- 图表展示模型图例，悬停某天时显示日期和各模型整数百分比。
- 标题为“近 7 天 · 套餐用量”，并提示官方数据最多延迟 6 小时。
- Claude、WorkBuddy、DeepSeek 图表保持原样。

## 验证方式

- 单元测试覆盖凭据解析、请求域名与参数、跨域拒绝、响应解析、七日补零和安全降级。
- 单元测试覆盖模型排序、“其他”合并、显示名称及官方数据与账号 Token 合并。
- 运行完整测试、Release 构建和应用打包；正式应用仅在再次授权后替换。
