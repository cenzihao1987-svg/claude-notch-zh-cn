# 界面语言切换

## 目标

在现有齿轮设置菜单中增加“语言 / Language”选项，允许用户在“中文”和“English”之间切换；切换立即生效，并在下次启动时保持。

## 范围

- 默认语言保持中文，不根据系统语言自动改变，避免升级后界面突然变化。
- 覆盖刘海收起态、展开态、设置菜单、额度与重置文案、任务列表、Agent 状态、接力入口、错误/等待提示和 Codex 桌面小组件。
- 任务名、项目名、套餐名、Agent 名称及网站名称属于原始内容，不自动翻译。
- 交接包和交给目标 Agent 的任务指令不随界面语言改变，避免改变既有跨 Agent 交接协议。
- 语言偏好保存到本机 `UserDefaults`；桌面小组件通过现有 App Group 同步同一偏好。

## 界面

- 设置菜单增加二级菜单：中文界面显示“语言”，英文界面显示“Language”。
- 二级菜单固定显示“中文”和“English”，当前语言左侧显示勾选。
- 不新增设置窗口，不改变现有菜单顺序、卡片尺寸或交互方式。

## 降级

- 找不到语言偏好或偏好值损坏时回到中文。
- API 返回的未知状态或用户生成内容保持原文，不猜测翻译。

## 验证

1. 在中文和 English 间切换时，当前展开界面与设置菜单立即更新。
2. 重启应用后仍保持上次选择。
3. 两种语言下卡片尺寸、任务行和接力按钮不溢出。
4. Codex 桌面小组件跟随语言偏好更新。
5. 完整单元测试、Release 构建、`git diff --check`、ad-hoc 签名和真实界面检查通过。
