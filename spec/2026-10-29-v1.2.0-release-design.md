# v1.2.0 守护启动公开版

## 行为

- **首次欢迎卡**：首次运行时在刘海显示欢迎卡，包含三步：专属环境（按出口 IP 推荐，可修改）、开机自动运行刘海（按用户开关注册）、开启防护并启动 Claude。可以选择“稍后”。
- **未防护提醒**：出现以下任一情况时，盾牌旁显示“未防护”：
  - 专属配置已开启，但运行中的实例不是从刘海启动的，或存在多个实例；
  - 刘海启动后，专属配置又发生了变化；
  - 专属配置已关闭，而 Claude 仍在运行。

  横幅提供“以防护重启”：先确认，再走启动前网络检查，然后正常退出，不强制结束。× 只忽略当前实例。
- **风险逐条处理**：
  - 横幅中每项一个行内操作，状态依次为“待处理 → 复查中 → 已处理”。
  - 悬停 × 只忽略该项，不清除风险记录与评分。
  - 全部处理完后转绿并收起。
  - “无法核验”“无法确认”两类恢复行内的“重新检查”。
  - Clash 只读检查，不切换模式。
- **出口查询**：
  - 运行中的后台查询：超时 12 秒，失败后 5 秒复测一次，连续两次失败才提示“无法确认”；取消与过期的任务不重试。
  - 启动前检查：仍为单次 5 秒查询，结果异常或未知时默认取消。
- **资源占用**：
  - 图标只在 agent 非空闲时动画。
  - Claude Desktop 缓存只看新写入的文件；订阅资料只查最近 256 个文件，每 10 分钟查一次。
  - 日志大小不变时，状态圆点复用上次结果。
  - 用量快照缓存排序、去重后的事件。
- **额度**：
  - 识别带查询参数的 `/usage` 缓存条目。
  - 15 分钟内的读数视为最新；更早的读数保留，并标明更新时间。
  - 凭据兜底默认关闭，与之前一致。
- **订阅等级**：Desktop 缓存没有组织资料时，只读取 `~/.claude.json` 的 `oauthAccount.organizationType`，不读取凭据。
- **公网 IP**：环境窗口“当前系统环境”显示公网 IP，复用已有的出口观测，不新增请求。

## 隐私

- 不修改系统代理、VPN 或 Claude 账号数据。
- 额度读取不新增网络请求。
- IP 不写入日志、通知或公开材料；演示图使用保留地址段。

## 发布与验证

- **发布内容**：源码、测试、中英文说明、发布说明和原生界面演示图。
- **不发布**：本机配置、历史与验证记录、客户端备份、安装包和视频工程。
- **演示图**：
  - 首页主图取自界面设计定稿 `效果图/横幅处理与首次引导-20261029/定稿.html` 中的「未防护提醒」画布，只截画布与右侧说明，不含评审备注。
  - 欢迎卡图由 DEBUG 构建通过独立假数据模型与真实 SwiftUI 组件离屏渲染，按刘海屏的 Retina 倍率输出。
  - 两张图都只用演示数据，未采集真实账号、任务或出口。
- **发布前**：选定的源码快照能独立运行全部 271 项 Swift 测试，并完成 Release 构建。
- **安装包**：由 v1.2.0 标签对应的源码构建，附 SHA-256；发布后下载回来复核。
