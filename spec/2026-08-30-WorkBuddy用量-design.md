# WorkBuddy 用量与近期任务

日期：2026-08-30

## 目标

在刘海展开态新增 WorkBuddy Tab，顺序为 Claude、Codex、WorkBuddy、DeepSeek。WorkBuddy 展示
账号积分、套餐、刷新/到期时间、最近更新的三条任务和本机最近七天的每日积分消费。

## 数据边界

- 账号数据只读取 WorkBuddy 共享登录文件中的当前访问令牌和账号 ID，并且只请求
  `https://copilot.tencent.com` 的计费端点。
- 每日积分改为只读 WorkBuddy 本机数据：从 `~/.workbuddy/workbuddy.db` 的
  `session_usage.credit_json` 取得请求积分，再从 `~/.workbuddy/projects` 的任务 JSONL 中只匹配
  `providerData.conversationRequestId` 与 `timestamp`，按本地日历汇总最近七天。
- 不读取 Chrome Cookie、不访问 WorkBuddy 网页端、不调用钥匙串或 Touch ID。解析任务 JSONL 时不保留、
  不缓存、不记录 Prompt、回复、工具输出或原始行；无法匹配到时间的积分不推算。
- 令牌、刷新令牌、账号 ID、原始响应不写日志、不持久化、不进入错误提示。令牌失效时不主动续期。
- 成功后只缓存账号积分、套餐和时间等非敏感数值；本机每日积分仅做 60 秒内存缓存。
- 近期任务只读 `~/.workbuddy/workbuddy.db` 的 `sessions` 和 `session_usage` 表，使用只读 SQLite
  连接以兼容 WAL；不读取消息、提示词、工具输出和对话记录，也不修改 WorkBuddy 文件。
- 有本机目录和主任务 JSONL 的 WorkBuddy 近期任务可接力到 Claude 或 Codex。交接时才从对应 JSONL
  读取最后 2 MB：只提取 `<user_query>` 中的显式用户请求与最后一条可见 `output_text`，忽略系统提醒、
  推理、工具调用、工具结果和 `rawContent`；内容经过既有密钥/敏感路径脱敏后才写入交接包。缺目录或记录的
  旧任务不显示接力按钮。

## 界面与刷新

- 收起态显示 WorkBuddy 白色标志、剩余积分百分比和环形进度；用户选择会被记住。
- 展开态左侧使用 2×2 卡片：剩余额度、已用积分、当前套餐、刷新或到期时间；右侧使用与 Codex
  相同尺寸的“近 7 天 · 本机消耗”柱图并支持小数积分。该图不承诺包含网页端、移动端或其他电脑的消耗。
- 下方固定显示最近更新的三条任务，行高始终为 22pt；具备安全本机记录的任务在悬停时显示“接力”按钮。
- 选中、展开和手动刷新时立即更新余额与任务；展开选中时最多每 60 秒更新，收起选中时最多每 5 分钟更新。
  本机每日积分最多每 60 秒重新扫描一次，手动刷新可跳过限制；未选中或暂停检测时不扫描。
- 内部计费接口或本地数据库失效时显示真实状态，已有成功结果保留并变暗。

## 验证方式

1. 固定样本覆盖个人/企业账号、零或无限额度、多资源包、过期令牌、401、429、网络失败和异常响应。
2. 验证请求积分与任务时间匹配、重复事件去重、子 Agent 记录、七日窗口、跨月、全零和缺失日期补零；
   确认源码不再编译或调用 Chrome、Cookie、Touch ID 与网页用量链路。
3. 验证 SQLite WAL、损坏/缺失数据库、删除任务、标题回退、排序和三条限制，以及主任务 JSONL 与目录
   匹配后才开放接力。
4. 验证 WorkBuddy 交接只携带显式用户请求和可见回复，排除系统提醒、推理与工具输出；验证 Tab 顺序、
   语言、2×2 与周图布局、收起循环和 22pt 任务行。
5. 用已登录 WorkBuddy 实机对照积分、套餐、刷新时间与最近任务；运行 release build、`git diff --check`、ad-hoc 打包和真实刘海检查。


## 2026-10-15 WorkBuddy 5.8.2 加密登录兼容

用户报告刘海显示“未找到登录信息”。实机确认原共享登录文件仍在，当前 `accessToken` 已从字符串改为 `$wbEncrypted:1` 的标准加密字段；旧 JSON 解码失败被吞掉后误报为未登录。

兼容已有明文格式与新版标准字段格式。新版仅将当前 `accessToken` 的密文经私有管道交给已安装 WorkBuddy 自带的 Electron 运行时，复用其本机存储组件提供的密钥能力，按当前客户端 WBEV1／sym-v1 认证格式解码。当前访问令牌仅在短生命周期子进程及额度请求内存中使用；不读取 `refreshToken`，不解密其他账号字段，不修改 WorkBuddy 程序、登录文件或加密策略，不保存或记录密钥／令牌。子进程有超时与输入输出大小限制，未知格式和验证失败如实报告无法读取，不能再误报为没有登录信息。

仍只调用原有只读计费端点，保留缓存与本机每日积分链路，不恢复已停用的 Chrome／网页登录抓取。应用标识、跳转与其他功能不在此次修复范围。

### 兼容验证

- 使用合成样本验证旧格式、新格式、仅解密当前访问令牌，以及未知保护格式拒绝降级。
- 验证 AES-GCM 身份校验、密文篡改、错误密钥、无效长度及失败输出不含输入内容。
- 实机通过原有额度接口和本机每日积分集成测试；真实凭据和原始响应不进入测试输出。
- 完整 Swift 测试、Release 构建、资源打包和本地签名验证；保留旧版备份后更新本机应用，手动界面验收交给龟。
