# 多屏刘海与运行状态

## 目标

- 展开与收起共用一套连续布局，顶部图标和用量圆环两个方向都平滑位移。
- 展开动画期间移动鼠标不得触发收起再展开。
- 用量圆环在展开态右侧额外增加 8px 留白。
- 每块已连接的屏幕顶部都显示刘海，各窗口独立展开和收起，共享同一份用量数据。
- 收起态仅在非空闲时于当前来源图标左侧显示状态点，展开态隐藏。

## 状态口径

- 待确认（橙色）：本地任务记录明确停在用户输入/确认请求。
- 思考中（蓝紫色）：最新事件是模型推理，且任务尚未完成。
- 工作中（绿色）：最新事件是工具执行或结果处理，且任务尚未完成。
- 空闲（不显示）：任务已完成、应用未运行、记录过旧或无法可靠判断。
- Claude 优先读取桌面端 `local-agent-mode-sessions` 审计事件中的状态与权限请求，无可用事件时再回退到本地会话事件。
- 仅使用 Claude/Codex 已有本地事件的类型、时间和工具名；不记录、不展示对话正文。

## 窗口规则

- 有实体刘海的屏幕使用真实安全区尺寸。
- 外接屏幕使用 190×32px 的虚拟刘海。
- 屏幕插拔时增删对应窗口，不重启数据源。
- 任意一个窗口展开时可触发一次最新数据刷新，不因多屏成倍请求。

## 验证方式

1. `swift build -c release` 编译通过，`git diff --check` 无格式错误。
2. 展开后移动鼠标，形变不反向跳动；收起时图标和用量圆环与外形同步回位。
3. 枚举当前所有 `NSScreen`，每块屏幕各有一个窗口；在不同屏幕悬停时只改变对应窗口。
4. 收起态仅在工作、思考或待确认时显示状态点；展开态和空闲时不显示。
