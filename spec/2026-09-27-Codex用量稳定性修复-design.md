# Codex 用量稳定性修复

## 目标

新版 Codex 客户端仍能读取额度；重复任务或部分请求失败时，刘海不崩溃、不把已成功读取的额度清空。

## 实现

- 补充当前 Codex 内置命令程序路径。
- 近期任务按 ID 去重后再读取 Token 与展示，避免重复键崩溃。
- Codex 额度、Token 和任务请求返回不齐时保留已收到的部分；额度读取失败时显示上次值并标为过期，成功后恢复实时值。
- 移除桌面小组件，继续保留刘海内的 Codex 用量。

## 验证方式

- 重复任务单元测试、额度失败保留与恢复单元测试。
- 完整 Swift 测试、真实 Codex 用量读取、Release 构建、签名校验和安装启动检查。
