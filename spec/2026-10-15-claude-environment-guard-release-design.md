# Claude 环境守护 · v1.1.0 发布设计

## 定位与已有能力

保留 Claude、Codex、WorkBuddy、DeepSeek 的额度或余额监测、趋势图、近期任务及任务接力。环境守护是 v1.1.0 新增核心能力：保留用户 Mac 使用习惯，尽可能降低可控的 Claude 环境风险。界面聚焦风险、守护状态和可执行操作，不重复强调免责声明。

## 环境与启动

- 仅在 Claude 页显示环境盾牌入口。独立窗口以原生设置面板配色为准，失焦不关闭，也不阻止刘海展开。
- 紧凑展示系统语言、地区、时区及风险；主区域并排显示保存配置与网页实际值，外显出口国家和城市。
- 专属配置默认关闭，只对本工具启动的 Claude 生效。语言、地区和进程时区分别保存，地区联动推荐时区，按地区记住手动时区选择；不改 macOS 全局设置、输入法或 VPN。
- 配置开启时通过现有启动器应用配置。关闭时保存状态并保留配置；运行中的 Claude 提供“重启 Claude／稍后”原生确认框。
- 正常退出完成后才创建新实例。拒绝退出、取消退出或超过 15 秒均停止重启，不强制结束用户进程；启动失败用原生弹窗说明。

## 核验与风险

- 上下环境使用同一网络和客户端快照，本地特征最高 40、网络最高 40、客户端最高 20。关联本地信号去重，中文语言本身不计分；必要数据缺失时显示未知值。
- 低风险（0–19）圆环为白色，其他已知分数为强调橙色。重新检测显示加载状态，结果使用已有圆环与数字过渡，不增加进度区域。
- 出口查询仅请求国家、城市等参照信息，不保存原始 IP、不接管网络；核验信息可以关闭此探测。VPN 分流时参照出口可能不同于 Claude 的实际出口。
- 网页采集仅读取实际 Claude 页面或明确的本地主界面中的语言、语言列表、Intl Locale 与时区，绑定进程、启动回执及单次会话标记。缺失、旧实例、过期或部分失败均不算通过，不能用配置值补齐实际值。
- 网页模块及地区适配须经用户同意，完整备份原客户端后生成暂存副本并本地重签。保留原调试限制、ASAR 完整性校验；不开放调试端口，不读取聊天、账号、Cookie 或网页存储。地区覆盖通过客户端进程内接口设置，实际值仍由采集模块独立核对。
- 当前适配目标为 Claude Desktop 2.37337.1；版本变化需先检查，再重新适配，不能自动修改未知客户端。

## 其他修复与验证

WorkBuddy 兼容当前加密登录，仅在内存中解码当前访问令牌供已有额度查询，不续期、不记录或保存令牌。四个工具的失败状态旁提供原位重试，复用现有刷新入口并阻止重复请求，保留暂停检测与凭据授权边界。

发布前运行完整 Swift 测试、网页采集与登录解码 Node 测试、签名脚本 Python 测试及 Release 构建。使用原生示例截图核对布局与配色；示例保留标记，手动交互验收由用户负责。公开源码排除所有客户端副本、备份、登录数据、调试记录和本机路径，仅提供源码归档，不发布本机自签名应用或修改后的 Claude 客户端。
